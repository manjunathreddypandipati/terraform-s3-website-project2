# Project 2 - Host a Static Website on Amazon S3 using Terraform

## Objective
Host a static website on Amazon S3 using Terraform.

## AWS Services Used
- Amazon S3
- Terraform

## Resources Created
- S3 Bucket
- Static Website Hosting Configuration
- Public Access Configuration
- Bucket Policy
- Website Content (index.html)

## Project Files
- provider.tf
- s3.tf
- outputs.tf
- index.html

## Deployment Steps

terraform init

terraform validate

terraform plan

terraform apply

## Verification

The website is hosted using Amazon S3 Static Website Hosting and is publicly accessible through the generated website URL.
